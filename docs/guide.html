📊 板塊輪動掃描器 — 使用指南

簡單指南：教你睇明呢個工具顯示咩，同埋應該點行動。

⚡ 30秒快速上手

你要做嘅就係：

  1. 打開儀表板。
  2. 睇最頂綠色「買入」嗰幾行。呢啲係 ETF（交易所買賣基金——即係一籃子股票，可以當一隻股票咁買賣），而家條件有利。
  3. 睇信心度百分比。愈高代表愈多因素一致。想要高信心機會，就揀65% 以上。
  4. 睇理據欄。佢會用淺白文字話你知點解。
  5. 如果你持有嘅嘢被標「賣出」或「減持」，考慮減倉或離場。

基本就係咁。呢頁下面會解釋訊號背後嘅原理。

💡 核心理念（唔講術語）

將股市想像成一棟大廈，入面有唔同房間——科技、醫療保健、能源、黃金、債券等等。資金不斷喺呢啲房間之間流動。

呢個工具監察資金行緊入邊間房（對嗰個板塊係好事）同資金離開緊邊間房（壞事）。佢亦會睇間房係啱啱開始有人入（早，入場時機好）定已經逼爆（遲，逼夾，風險高）。

最理想情況：資金流入緊一間未逼爆嘅房。呢個就係機會。

信心度數字

將信心度想像成天氣預報：「70% 會落雨」即係幾個指標都話會落，但唔係保證。

  • 65-80%： 多個因素一致，係最好嘅機會。
  • 50-64%： 有啲證據，但唔算壓倒性。有都只係細注。
  • 50%以下： 訊號弱，唔好單靠佢行動。

📈 趨勢階段（而家行到邊？）

每項投資都有周期，好似四季。知道而家係咩「季節」，就知係咪入場好時機：

階段季節比喻對你嘅意思
⬆ 早期升勢 🌱 春天——啱啱開始 買入最佳時機。趨勢新鮮，上升空間大。
⬆ 升勢確立 ☀️ 夏天——開到荼蘼 回調時買入。趨勢已確認，健康。
⚡ 過熱 🥵 盛夏——太熱 太遲，唔好追。有貨嘅考慮食糊。
↪ 回調 夏天短暫涼快幾日 如果大趨勢仲向上，可能係買入機會。
⬇ 早期跌勢 🍂 秋天——轉勢 走。唔好等佢彈返。
⬇ 跌勢確立 ❄️ 冬天——確認凍 唔好掂。唔好喺呢度「撈底」。
↩ 反彈 冬天一日暖 短暫——唔好受呃，跌勢未完。

🌍 資產類別資金流（睇大局）

揀板塊之前，先睇大局：資金整體係流入股市，定係逃緊去避險？

例子：避險（市場驚）

美股 → 流出

債券 → 流入

黃金 → 流入

解讀：投資者賣股票買避險資產。唔係買進取板塊嘅好時機，揀防守板塊（公用事業、醫療保健）或債券／黃金。

例子：冒險（市場有信心）

美股 → 流入

債券 → 流出

黃金 → 流出

解讀：資金由避險資產流入股市。利好增長板塊（科技、非必需消費）。

🔄 板塊輪動（股市入面揀邊瓣？）

就算大市整體ok，唔同板塊都有升有跌。輪動話你知聰明錢喺股市入面行緊去邊。

要睇嘅關鍵形態：

  • 增長板塊領先（科技、非必需消費、通訊服務）→ 市場預期經濟增長，利好。
  • 防守板塊領先（公用事業、醫療保健、必需消費）→ 市場開始驚，資金匿入防守股，可能係大市回調前兆。
  • 「排名變化」欄顯示動量。正數代表嗰個板塊爬升得比同業快，緊追緊排行榜。

📋 實戰例子

情境：你打開儀表板，見到最頂係：

買入 XLU（公用事業）— 信心度：75%

「新升勢形成，資金流入確認」

諗法係咁：

  1. XLU 係咩？公用事業板塊 ETF——電力公司、水務公司。悶但穩。
  2. 點解買入？工具偵測到公用事業啱啱起步向上（早期升勢），又有資金流入（流入確認）。兩個訊號一致＝75%信心度。
  3. 睇埋大局：睇資產類別資金流。如果美股流出、債券流入，即係防守性輪動——公用事業作為避險選擇就合理。
  4. 點行動：喺券商買入 XLU。注碼睇信心度——75%可以足注，60%就半注。
  5. 幾時賣：訊號轉做減持或賣出，或者趨勢階段變成「過熱」或「早期跌勢」。

🚫 常見錯誤

  • 唔好買「過熱」訊號。已經升咗好多，你遲咗。等回調或者睇第二樣。
  • 唔好無視賣出訊號博反彈。壞咗嘅趨勢通常會再衰啲先好返，早啲止蝕。
  • 唔好喺跌勢中追反彈。「逆勢反彈」唔係復甦——係陷阱，呃人喺下一浪跌之前買入。
  • 唔好 all-in 單一訊號。分散 2-3 個買入訊號，唔好成副身家押一隻板塊。
  • 唔使成日睇。呢個每日收市後先更新一次，睇密啲無幫助。

⚠️ 呢個工具做唔到咩

  • 預測唔到突發事件。業績公布、議息、戰爭、疫情可以一夜之間推翻所有訊號。
  • 佢係睇過去。佢量度已經發生嘅事。「早期升勢」已經係佢俾到最好嘅嘢——都係建基於近期價格走勢，唔係水晶球。
  • 佢唔識你嘅情況。你嘅風險承受力、投資年期、現有組合都重要。25歲同退休人士面對同一個訊號應該有唔同做法。
  • 訊號會變。今日買入，下星期可以變持有。定期返嚟睇，但唔使為日日嘅變化驚慌。
